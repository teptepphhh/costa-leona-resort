What I would do next

  1. MongoDB authentication (the gap named in the Well-Architected review): store a database password in Parameter Store and require it, plus a secret header so only CloudFront can talk to the origin. About one hour.
  2. Automatic recovery and off-instance copies: daily EBS snapshots with Data Lifecycle Manager and an auto-recovery alarm on the instance; later a second Availability Zone behind a load balancer. This lifts Reliability from adequate to good.
  3. Deploy from Git automatically: a GitHub Actions workflow that runs the tests and then the SSM command that already pulls and restarts the stack, so a change to main updates the running system.
  4. Better quality measurement: grow the labelled set well past 30 questions written by someone else, add checks for capacity and arithmetic (the failing test T3), and add a thumbs-up/down feedback metric from real guests.
  5. Protect the free model quota: rate limiting or AWS WAF in front of CloudFront, and an alarm on request volume, so a loop or a bot cannot burn the quota or, on a paid key, the budget.
